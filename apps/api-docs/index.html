Auth

Routes for authentication

auth/signup

Creates a user and sends a validation code to email. This route can be used to create a athlete, coach or admin.

Request Body schema: application/json
required

A basic information about user. If the user is a athlete, the coachId is required.

firstName
required
string
lastName
required
string
email
required
string <email>
password
required
string >= 8 characters
role
required
Array of strings unique
Items Enum: "ATHLETE" "COACH" "ADMIN"

Responses
