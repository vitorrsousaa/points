Route to get all workout review data. It's necessary to set coachId or athleteId to filter the data.

Authorizations:
CognitoAuthorizer
query Parameters
coachId
required
string (coachId-d83636ec-2dc0-49e3-893f-b79a7ac0b9b7)
Example: coachId=4df43fc4-fbf5-4286-9b51-edf852db180d

The coachId to filter coach

required
string (athleteId-2a4ec99a-0dc8-46da-a01d-518402b76369)
Example: athleteId=4df43fc4-fbf5-4286-9b51-edf852db180d

The athlete who owns the workout

reviewed
required
boolean (reviewed)
Example: reviewed=true

The queryParams define if the workout was reviewed or not. If true, the workout was reviewed. If false, the workout was not reviewed.

limit
required
boolean (limit)
Example: limit=10

The limit of items to return. Default value is 5.
